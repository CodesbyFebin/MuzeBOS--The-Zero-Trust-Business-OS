# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code rather than people, and keep discussion on topic. Harassment, discrimination and personal attacks are not tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainer through a [GitHub security advisory](https://github.com/CodesbyFebin/MuzeBOS--The-Zero-Trust-Business-OS/security/advisories/new) or a direct message to @CodesbyFebin. Reports are handled confidentially. The maintainer may remove comments, commits or contributors that break this code.

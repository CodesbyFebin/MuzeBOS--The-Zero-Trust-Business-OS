# Design reference

`metabos-reference.html` is a visual mockup supplied by the owner (dark UI, #00FF9D accent, Inter / JetBrains Mono). It is a **design reference only**: its figures (e.g. "1,247 runs", "99.2%", "92% reply chance") and any implication that emails were sent are illustrative mock data, not product data. The app shows only stored records or "No records yet". No restyle was applied.

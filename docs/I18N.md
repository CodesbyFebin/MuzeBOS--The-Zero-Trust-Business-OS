# Interface languages (batch 3)

Strings: lib/metabos/b3/i18n/{en,hi,ml,ta}.json (30 keys). The language is picked at /workspace/settings/language and stored in the mb_lang cookie. The Orders/Money/Talk KPI cards and their empty state use it so far.

## How they were made
90 translate jobs ran on the local claw-local Sarvam model (free; Llama Guard 3 1B checked each one). The model also translated the instruction text, so the label was taken after the final colon. Then I reviewed every row by hand:

- hi.orders: 'आदेश' -> 'ऑर्डर'
- hi.approve: 'अनुमोदन के लिए जेव को भेजें' -> 'मंज़ूरी के लिए Jev को भेजें'
- hi.pendingJev: 'जेव में लंबित' -> 'Jev में लंबित'
- ml.talk: 'സംസാരിക്കുക' -> 'സംസാരം'
- ml.approve: 'അംഗീകാരത്തിനായി ജെവിക്ക് അയയ്ക്കുക' -> 'അംഗീകാരത്തിനായി Jev-ലേക്ക് അയയ്ക്കുക'
- ta.language: 'இந்த குறுகிய வணிக பயன்பாட்டின் யுஐ லேபிளை இலக்கு மொழிக்கு மொழிபெயர்க்கவும். மொழிபெயர்ப்புடன் மட்டும் பதிலளிக்கவும்' -> 'மொழி'
- ta.unpaid: 'நிலுவைத் தொகை' -> 'செலுத்தப்படாத விலைப்பட்டியல்கள்'
- ta.approve: 'ஒப்புதலுக்காக ஜெவ்விற்கு அனுப்பவும்' -> 'ஒப்புதலுக்காக Jev-க்கு அனுப்பவும்'- Llama Guard flagged 8 Malayalam labels as S8 and 1 Tamil label as S5. Reviewed: they are plain UI words (false positives), so they were kept.
- 3 jobs failed (hi.customers, ml.brain, ta.money). Those keys show English.
